# Upbit Smart Trader — 모의매매 PWA v1

## 사용법
1. 이 폴더의 파일을 정적 HTTPS 호스팅(GitHub Pages, Netlify 등)에 업로드합니다.
2. Android Chrome에서 배포 URL을 열고 메뉴 → 홈 화면에 추가 / 앱 설치를 선택합니다.
3. 시세 연결과 차트 데이터가 표시되면 자동매매 시작을 누릅니다.

## 주의
- 실제 업비트 주문 API는 사용하지 않습니다. API 키를 입력하지 마세요.
- 모의 잔고/거래내역은 현재 브라우저 localStorage에 저장됩니다. 기기·브라우저 사이에 동기화되지 않습니다.
- 브라우저 화면이 닫히거나 OS가 백그라운드 실행을 제한하면 자동매매가 멈춥니다.
- 브라우저 알림은 실제 서버 푸시가 아니며, 브라우저가 실행 중일 때만 기대할 수 있습니다.
- 모의체결은 공개 ticker 가격을 기준으로 하며 호가, 체결 지연, 슬리피지를 반영하지 않습니다.
- EMA/RSI/MACD 기반 진입 규칙은 실험용이며 성과 검증을 거치지 않았습니다.
- 공개 API 연결 상태, CORS, 서비스 정책 및 브라우저 환경에 따라 시세 조회가 실패할 수 있습니다.
- 오프라인 캐시는 UI 실행을 위한 것이며 시세가 없으면 거래를 차단합니다.

## 주요 파일
- index.html: 대시보드
- app.js: 시세, 지표, 모의매매, 기록
- style.css: 모바일 UI
- manifest.webmanifest, sw.js, icon.svg: PWA 구성
