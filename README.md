# 업비트 모의 자동매매 PWA

업비트 공개 REST API를 이용하는 **모의매매 전용** 정적 웹앱입니다. 실제 주문이나 API 키는 사용하지 않습니다.

## GitHub Pages 설치
1. 이 폴더의 `index.html`, `app.js`, `style.css`, `manifest.webmanifest`, `sw.js`, `icon.svg`를 GitHub 저장소 **최상위 폴더**에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` 및 `/(root)`를 선택하고 Save합니다.
3. 몇 분 후 표시되는 `https://계정명.github.io/저장소명/` 주소를 안드로이드 Chrome으로 엽니다.
4. Chrome 메뉴 **홈 화면에 추가 / 앱 설치**를 선택합니다.

## 기능 및 주의
- 시작금 200,000원. 한 종목당 한 포지션, 초기 자동매매 OFF.
- 업비트 시세를 약 5초마다 REST 조회하며, 5분/60분 완성봉으로 EMA(9,21), RSI(14), 거래량 비율을 평가합니다.
- 매수: EMA9>EMA21, RSI 48~68, 최근 완성봉 거래량이 이전 20봉 평균의 1.15배 이상.
- 매도: 설정 익절/손절, EMA 역전+RSI 약세, 데이트레이딩 일자 변경, 스윙 7일 경과.
- 편도 수수료 0.05%, 사용자 설정 슬리피지 반영. 실시간 호가·체결 시뮬레이터는 아니므로 실제 체결과 차이가 납니다.
- 보유 포지션은 브라우저에 저장됩니다. CSV 내보내기를 지원합니다.
- **중요:** 정적 GitHub Pages 앱은 브라우저가 백그라운드/종료되면 자동매매가 멈춥니다. 앱을 다시 열어도 자동매매는 OFF로 시작합니다. 24시간 자동 실행은 별도 서버가 필요합니다.
- 투자수익, 5% 목표, 승률은 보장되지 않습니다. 교육용입니다.
